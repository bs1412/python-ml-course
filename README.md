# Python 机器学习课程实验 📊

机器学习课程的实验代码整理，涵盖分类、聚类、特征选择等常见算法，以及一个期末项目（自实现机器学习算法库 + 数据分析）。

## 📚 内容

- 决策树预测 —— 糖尿病预测
- 支持向量机 —— 糖尿病数据集分类
- 近邻分析（KNN）—— 牛奶质量预测
- 朴素贝叶斯 —— 文本分类
- 神经网络 —— 肥胖风险数据集
- 聚类分析 —— K-Means
- 特征选择 —— Dry Bean 数据集
- 章节练习 —— 教材第 10 章练习
- final-project —— 期末项目：自实现算法库 + 数据分析

## 🛠️ 技术栈

- Python 3
- scikit-learn、pandas、numpy、matplotlib
- 自实现算法：决策树、KNN、K-Means、线性回归、朴素贝叶斯
